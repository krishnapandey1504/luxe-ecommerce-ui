# LUXE – Luxury Fashion Website UI

A premium luxury fashion website UI created during a college frontend workshop using pure HTML and CSS.

## ✨ Features

- Modern luxury fashion design
- Fully responsive layout
- Premium UI cards
- Hero section
- Featured products section
- Summer sale banner
- Footer with newsletter
- Smooth responsive scrolling cards
- Mobile, tablet and desktop optimized

## 🛠️ Technologies Used

- HTML5
- CSS3
- Remix Icons
- Google Fonts

## 📱 Responsive Design

The website is fully responsive across:

- Desktop
- Laptop
- Tablet
- Mobile Devices
